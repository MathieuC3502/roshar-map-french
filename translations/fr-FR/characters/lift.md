# Lift

> Il faut bien que quelqu’un s’en soucie. Y a trop peu de gens qui le font ces jours-ci.

**Lift** est une voleuse Reshie qui oeuvrait dans la cité d'#[Azimir](locations/azimir), dans la nation rosharienne d'#[Azir](locations/azir). Liée à Wyndle, c'est une Fluctomancienne de l'ordre des Dansecorde.
