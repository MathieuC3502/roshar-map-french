# Culture

> Je contrôle toutes les choses qui peuvent être cultivées, nourries. 
> Y compris les épines.

**Culture** est l'un des seize Éclats d'Adonalsium. Elle réside sur Roshar, étant à l'origine venue avec #[Honneur](characters/honor) avant l'arrivée #[d'Abjection](characters/odium). Le nom de son Vaisseau est inconnu, bien qu'#[Hoid](characters/wit) l'appelle **Slammer**. L'Investiture de Culture est généralement associée à la couleur verte.
